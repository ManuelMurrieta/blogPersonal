# Entreacto — Blog personal (PHP + Vercel)

Estructura solicitada:
- `api/index.php`: Punto de entrada principal y enrutador para Vercel.
- `secciones/`: Vistas PHP modulares (`inicio.php`, `ensayo.php`, `notas.php`, `sobre-mi.php`).
- `datos/`: Contenido en JSON (`ensayos.json`, `diario.json`).
- `public/`: Recursos estáticos (`style.css`, `favicon.svg`).
- `vercel.json`: Configuración del runtime PHP y rutas limpias en Vercel.
